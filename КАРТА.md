# Карта проекта AxGram

Документ описывает оба проекта целиком: что где лежит, какой файл за что
отвечает, как собрать и поставить, и на какие грабли уже наступали.

Копия этого файла лежит в обоих репозиториях. Правишь один — правь и второй.

---

## 1. Что это такое

AxGram — два самостоятельных клиента Telegram под одним именем:

| | Android | Windows |
|---|---|---|
| Исходники | `D:\ABuild\Nagram` | `D:\TBuild\tdesktop` |
| Имя пакета / файла | `one.axgram.android` | `AxGram.exe` |
| Версия | 12.10.0 (код 7031) | 7.0.9 (`AppVersion 7000009`) |
| Ветка | `axgram` | `axgram` |
| Репозиторий | `aevornyx/axgram-android` | `aevornyx/axgram-desktop` |
| Слой протокола | LAYER 229 | LAYER 228 |

Общего кода у них нет. Это разные языки, разные сборочные системы и разные
предки — совпадает только название, оформление и набор возможностей.

### Происхождение кода

```
Telegram for Android  ->  Nekogram  ->  NekoX  ->  Nagram  ->  AxGram
Telegram Desktop      ->  AyuGram Desktop  ->  AxGram Desktop
```

Каждое звено — форк предыдущего под GPL-3.0. Отсюда важное следствие: в коде
встречаются три слоя авторства, и они по-разному трогаются.

* **Telegram** — исходный код. Правим точечно, каждую правку помечаем.
* **Донор** (Nagram / AyuGram) — то, что форк добавил до нас. Основной объём
  возможностей.
* **AxGram** — наше.

Лицензия требует сохранять уведомления об авторстве и помечать изменённые
файлы. Шапки вида «Основано на исходном коде AyuGram for Desktop,
Copyright @Radolyn» трогать нельзя — см. `NOTICE.md`.

## 3. Как собрать

### Android

```
D:\ABuild\build_apk.bat
```

Занимает 2–4 минуты. Что делает: выставляет `NATIVE_TARGET=arm64-v8a`, чтобы
NDK собирал библиотеки только под архитектуру подключённого телефона, и
запускает `gradlew.bat :TMessagesProj:assembleDebug`.

Результат:

```
D:\ABuild\Nagram\TMessagesProj\build\outputs\apk\debug\AxGram-v12.10.0-<код>-arm64-v8a-debug.apk
```

Установка на подключённый телефон:

```
adb install -r <путь к apk>
```

`adb` лежит в `C:\Users\kosta\AppData\Local\Android\Sdk\platform-tools\`.

**Собирать только из пути без кириллицы.** Android Gradle Plugin на путях с
русскими буквами падает — поэтому исходники лежат в `D:\ABuild`, а не на
рабочем столе.

### Windows

Три шага, но первые два нужны редко.

**Шаг 1 — Qt (один раз, около часа):**

```
D:\TBuild\build_qt.bat
```

Собирает Qt 5.15.19 с заплатками `desktop-app`. Запускать обязательно из
окружения Visual Studio: `prepare.py` проверяет переменную `Platform`, которую
выставляет `vcvars64.bat`. Аргумент `silent` обязателен — без него скрипт
останавливается на вопросе `(r)ebuild, rebuild (a)ll, (s)kip?` и ждёт нажатия
клавиши, которого в фоновом режиме не будет никогда.

**Шаг 2 — настройка (после смены версии Qt или правки CMake):**

```
D:\TBuild\configure_desktop.bat
```

**Шаг 3 — сборка:**

```
D:\TBuild\build_desktop.bat
```

Полная пересборка — около часа (1049 файлов, примерно 20 файлов в минуту).
Результат:

```
D:\TBuild\tdesktop\out\Release\AxGram.exe
```

Это самодостаточный файл, установщик не нужен. Рядом должен лежать каталог
`modules\x64\d3d\d3dcompiler_47.dll`. Если рядом с exe есть каталог `tdata`,
приложение работает в переносном режиме и хранит данные там.

### Подмодули

Четыре библиотеки форкнуты под нас и должны выкладываться вместе с основным
репозиторием — иначе клон не соберётся:

```
Telegram/lib_ui     ->  aevornyx/lib_ui
Telegram/codegen    ->  aevornyx/codegen
Telegram/lib_icu    ->  aevornyx/lib_icu
Telegram/lib_tl     ->  aevornyx/lib_tl
```

Проверить, что записанные коммиты есть на удалённой стороне:

```
git submodule foreach --recursive "git log --oneline @{u}..HEAD | wc -l"
```

Подмодуль `cmake` указывает на чужой `desktop-app/cmake_helpers`. Наши правки
туда не отправить, поэтому они сохранены заплаткой:

```
patches/cmake_helpers-local.patch
```

Применять после клона или обновления подмодуля — иначе сборка упадёт с C1041
или упрётся в память при компоновке.

### Схема протокола

```
Telegram/SourceFiles/mtproto/scheme/api.tl      LAYER 228
Telegram/SourceFiles/mtproto/scheme/mtproto.tl
```

Устаревший слой — причина сообщений «сообщение не поддерживается». При
обновлении слоя оба клиента поднимаются отдельно.

## 6. Что добавлено нами

* **Обход лимита папок.** Папки с номерами от 1000 — локальные, сервер о них не
  знает и не может их заблокировать. Порядок переживает перезапуск.
* **Архив удалённых.** Сообщения из удалённых чатов, групп и каналов остаются
  доступными вместе с названием чата. Экран двухуровневый, с обоями,
  разделителями дат и рабочими ссылками.
* **Архив одноразовых.** То же для исчезающих сообщений.
* **Свой канал обновлений** — релизы GitHub вместо чужих.
* **Вычищены чужие следы.** Методы оплаты донора, его QR-код, списки его
  аккаунтов с особыми значками, удалённая настройка с его сервера, ссылки
  exteraGram — удалены. Проверяется разбором строк готового бинаря.

## 8. Грабли, на которые уже наступали

**Файл подкачки.** Windows управляет им сам и после перезагрузки урезает.
Компоновщик десктопа держит 12 ГБ, компиляторы — по 2–6 ГБ каждый; при
автоуправлении сборка падает с C1060. Лечится один раз:
`D:\TBuild\set_pagefile.ps1` от администратора, затем перезагрузка. Ставит
фиксированные 32 ГБ на D: (SSD) и 2–4 ГБ на C: для аварийных дампов.

**`CL_MPCount=1` не уменьшает расход памяти, а увеличивает.** Единица отключает
многопроцессную сборку целиком, и один `cl.exe` компилирует все 1049 файлов, ни
разу не освобождая память — вырастает за 18 ГБ. Рабочее значение — 4.

**Кириллица в `.bat`.** `cmd` читает пакетные файлы в кодировке OEM, русские
комментарии превращаются в мусорные команды. Все `.bat` — только латиницей.

**`prepare.py` без `silent` зависает.** Ждёт нажатия клавиши на вопросе о
пересборке. В фоне это выглядит как работа: процесс жив, но процессорное время
не растёт. Проверять именно процессорное время, а не факт существования
процесса.

**Компоновка падает, если приложение запущено.** `LNK1104: не удаётся открыть
AxGram.exe` означает, что работает старая копия. Закрыть перед сборкой.

**`git add -A` затягивает вложенные репозитории.** `Telegram/ThirdParty/dispatch`
и `TMessagesProj/jni/libvpx` — самостоятельные репозитории внутри дерева.
Добавлять только поимённо.

**Кириллица в пути сборки Android.** Gradle Plugin падает. Исходники держать в
`D:\ABuild`.

## 9. Нерешённое

* **Чужие боты.** `ayugrambot` (дата регистрации) и `tgdb_search_bot` (поиск по
  идентификатору) в `ax/utils/telegram_helpers.cpp`. Запрос уходит только по
  нажатию, но владелец бота видит, чьи профили смотрят. Telegram дату
  регистрации по API не отдаёт — либо убрать функцию, либо поднять свой бот.
* **`dpaste.com`** в `ax/features/filters/filters_utils.cpp` — выгрузка папок при
  обмене.
