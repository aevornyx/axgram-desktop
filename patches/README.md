# Локальные заплатки

## cmake_helpers-local.patch

Подмодуль `cmake` указывает на чужой репозиторий `desktop-app/cmake_helpers`,
поэтому наши правки туда не отправить — они живут только в рабочей копии и
пропадают при `git submodule update --force` и при свежем клоне.

Что в заплатке:

* `/FS` в флагах MSVC. Без него параллельные `cl.exe` дерутся за один файл
  отладочной информации и сборка падает с C1041.
* Формат отладочной информации задан явно для каждой конфигурации и с `FORCE`.
  Иначе Release собирается со встроенной отладочной информацией, и линковка
  236-мегабайтного бинаря упирается в память.

Применить после клона или обновления подмодуля:

```
cd cmake && git apply ../patches/cmake_helpers-local.patch
```
